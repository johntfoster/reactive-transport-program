# Standing licensing policy — 2026-09-20

The owner selected Apache License 2.0 for code and Creative Commons Attribution
4.0 International for manuscripts as a standing policy for existing and future
work. This supersedes the undecided licensing status recorded in decisions
0002 and 0003; historical observations and release archives remain unchanged.

The four active papers now use these terms. Finite-strain already declared
both licenses, so its existing declaration and additional licensed materials
are preserved. The other active papers and both infrastructure repositories
receive license texts and explicit scope declarations. Third-party notices and
dependency licenses are preserved, not replaced by the owner policy.

No manuscript source, bibliography, figure, archived checkout, shared-workflow
pin, or scientific implementation is edited. Future project setup should read
licensing-policy.json and apply these defaults without asking again, unless the
owner explicitly requests an exception. This policy does not authorize changes
to manuscript content or expand the active development scope.
